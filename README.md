# APEX · תרשים מקצה לקצה

תרשים זרימה אינטראקטיבי של תהליך אוטומציית החיתום בביטוח חיים פרט, מגדל · תחום DATA ו-AI.

**צפייה בתרשים: https://muatom.github.io/apex_flow_diagram/**

---

## מה זה

התהליך כולו על קנבס אחד, מימין לשמאל, מרגע כניסת הפנייה ועד הפקת הפוליסה והפלט ללקוח.
שבעה אזורים: קליטה, פתיחת מקרה, ניתוב, פרופיל רפואי, מנוע החיתום, החלטה, וחתם והפקה.

שלוש רצועות אופקיות:

| רצועה | תוכן |
|---|---|
| עליונה | מערכות קיימות, ערוצי כניסה, ספקים חיצוניים ושירותי רוחב |
| אמצעית | הזרימה עצמה, כולל כל צמתי ההחלטה וההסתעפויות |
| תחתונה | מאגרי הנתונים והחוקות העסקיות |

כל רכיב משותף מופיע **פעם אחת בלבד**, עם כל החצים אליו וממנו. זה מה שמאפשר לראות
במבט אחד מי כותב לאיזה מאגר, מי קורא ממנו, ואיפה עוברים גבולות המערכת.

## איך משתמשים

| פעולה | תוצאה |
|---|---|
| גרירה | הזזת הקנבס |
| גלגלת | זום |
| `0` | התאמה למסך |
| לחיצה על צומת או חץ | מדגיש אותו ואת כל מה שמחובר אליו, עד `Esc` |
| `Esc` | ניקוי |

**מתג הגרסאות** למעלה מחליף בין Offline גרסה A, Offline גרסה B, ו-Online.
כפתור ה-`?` לידו מסביר מה ההבדל ביניהן.

**טוגלים:** `מיקוד אזור` מכהה כל מה שמחוץ לאזור שבמרכז המסך. `מיקוד בריחוף` מדגיש בריחוף ולא רק בלחיצה. `הבדלים מגרסאות אחרות` מציג בדהוי את מה ששייך לגרסאות האחרות.


## הקובץ

`index.html` הוא קובץ יחיד ועצמאי לגמרי. כל ה-CSS, ה-JavaScript, הגופנים והלוגו
מוטמעים בתוכו. אין תלות ברשת, ואפשר להוריד אותו ולפתוח מקומית.

לעריכת התוכן: המערכים `REGIONS`, `NODES`, `GROUPS` ו-`EDGES` מוצהרים ומתועדים
בראש הסקריפט. פריסת הצמתים וניתוב החצים מחושבים מהם, כך שאפשר להוסיף שלב או חץ
בלי לגעת בלוגיקת הרינדור.

## סטטוס

מסמך עבודה לצורך גזירת הארכיטקטורה הטכנית. שלוש שאלות פתוחות מסומנות בתג ענבר
על הצמתים הרלוונטיים.
